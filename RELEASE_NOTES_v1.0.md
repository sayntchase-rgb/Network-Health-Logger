# Network Health Logger v1.0

## Summary

Network Health Logger v1.0 is the first stable portfolio release of the project.

## Included

- Single-target connectivity checks
- Ping latency measurement
- HEALTHY / DEGRADED / DOWN classification
- Timestamped local logging
- Configurable target, timeout, latency threshold, and log path
- Reusable networking helpers in `chase_core`
- Automated unit tests
- GitHub Actions testing on Windows and Ubuntu with Python 3.11
- Execution screenshot and troubleshooting documentation
- MIT License

## Scope

Version 1.0 intentionally does not include dashboards, databases, alerting, continuous monitoring, or multi-target monitoring. Those are outside the stable v1.0 scope.
